# openDesk-specific Prometheus Alert Rules Helm Chart

A Helm chart for deploying prometheus alert rules as [PrometheusRule](https://prometheus-operator.dev/docs/api-reference/api/#monitoring.coreos.com/v1.PrometheusRule) objects.

## Prerequisites

Before you begin, ensure you have met the following requirements:

- Kubernetes 1.21+
- Helm 3.0.0+
- Prometheus Operator
- kube-state-metrics
